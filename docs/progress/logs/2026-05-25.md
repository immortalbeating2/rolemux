## 关键决策

- RoleMux 仓库自身使用 `AGENTS.md` 规范开发流程。
- RoleMux 产品安装到用户项目时默认不要求修改用户项目 `AGENTS.md`。
- `--with-agents` 只能作为显式可选能力。
- Subagent 设置采用角色模板方式写入 `AGENTS.md`，包括 researcher、architect、cli-builder、skill-builder、reviewer、docs-keeper。
- 三个留痕文档固定为：
  - `docs/progress/status.md`
  - `docs/progress/timeline.md`
  - `docs/progress/logs/YYYY-MM-DD.md`
- 用户要求的 `.codoex` 按 Codex 项目约定落地为 `.codex`，避免生成拼写错误目录。
- 注释策略采用“解释意图和边界，不逐行复述代码”：导出 API、provider adapter、跨平台路径、安全边界、task artifact schema、并发/fallback/超时等必须有注释。

## 影响范围

- 不涉及源码、CLI 命令、provider adapter、安装器或测试。
