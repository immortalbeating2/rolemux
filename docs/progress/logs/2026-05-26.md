# 2026-05-26 开发日志

## 本轮目标

根据用户要求补充 RoleMux 卸载功能，形成安装生命周期闭环。

## 设计边界

- 新增 `rolemux uninstall`。
- 支持 `--dry-run`，只列出卸载目标，不删除文件。
- 支持 `--keep-config`，保留 `~/.rolemux/config.toml`。
- 默认只删除 RoleMux 明确安装的路径：
  - `~/.rolemux/config.toml`
  - `~/.rolemux/roles/`
  - `~/.codex/skills/rolemux-workflow/`
  - `~/.claude/skills/rolemux-workflow/`
- 不删除用户项目文件，不修改或删除 `AGENTS.md`。
- 不整目录删除 `~/.rolemux`，避免误删用户自定义文件。

## 实施内容

- 新增 `src/commands/uninstall.ts`。
- 在 `src/cli.ts` 注册 `uninstall` 命令。
- 在 `src/index.ts` 导出 `uninstallCommand`。
- 新增 `tests/commands/uninstall.test.ts`，覆盖 dry-run、真实卸载和 `--keep-config`。
- 更新 `tests/cli-smoke.test.ts`，确认 CLI 注册 install/uninstall 生命周期命令。
- 更新 `README.md`、`docs/release/checklist.md` 和 `spec/rolemux-development-spec.md`。
- 更新 `docs/progress/status.md` 和 `docs/progress/timeline.md`。

## 风险与后续建议

- 当前卸载命令不删除 `~/.rolemux` 父目录，目的是避免误删用户自定义文件；README 已明确这一点。
- 后续若需要彻底删除空父目录，可新增显式选项，例如 `--prune-empty-dirs`，不要默认启用。
