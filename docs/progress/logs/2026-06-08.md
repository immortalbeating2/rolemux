# 2026-06-08 开发日志

## 本轮目标

使用 `plugin-creator` 将 RoleMux 生成并安装为 Codex Windows App 可用插件，使 Codex 插件系统可以从个人 marketplace 发现并加载 RoleMux workflow skill。

## 实施内容

- 读取 `plugin-creator` 技能说明，确认 Codex 插件必须包含 `.codex-plugin/plugin.json`，并默认使用个人 marketplace：`C:\Users\peng8\.agents\plugins\marketplace.json`。
- 使用脚手架创建个人插件源：

```powershell
python scripts\create_basic_plugin.py rolemux --with-skills --with-assets --with-marketplace
```

- 插件源目录：

```text
C:\Users\peng8\plugins\rolemux
```

- 个人 marketplace：

```text
C:\Users\peng8\.agents\plugins\marketplace.json
```

- 将仓库 Codex Skill 复制到插件：

```text
C:\Users\peng8\plugins\rolemux\skills\rolemux-workflow\SKILL.md
```

- 将仓库 README 复制到插件根目录：

```text
C:\Users\peng8\plugins\rolemux\README.md
```

- 更新插件 manifest：

```text
C:\Users\peng8\plugins\rolemux\.codex-plugin\plugin.json
```

manifest 使用 RoleMux 实际信息：

- `name`: `rolemux`
- `version`: `0.1.0`
- `displayName`: `RoleMux`
- `repository`: `https://github.com/immortalbeating2/rolemux`
- `skills`: `./skills/`
- 默认 prompt 覆盖 plan、dry-run、review 三类入口。

- 更新插件内 Skill：在 Windows Codex App 场景下，先用 `Get-Command rolemux` 检查 CLI 是否在 PATH；若缺失，只提示用户安装，不擅自安装。

## 安装到 Codex 插件系统

执行：

```powershell
codex plugin add rolemux@personal
```

结果：

```text
Added plugin `rolemux` from marketplace `personal`.
Installed plugin root: C:\Users\peng8\.codex\plugins\cache\personal\rolemux\0.1.0
```

## 已执行验证

```powershell
python -m pip install --user PyYAML
python scripts\validate_plugin.py C:\Users\peng8\plugins\rolemux
python scripts\read_marketplace_name.py
codex plugin list
codex plugin add rolemux@personal
python scripts\validate_plugin.py C:\Users\peng8\.codex\plugins\cache\personal\rolemux\0.1.0
Get-Command rolemux
rolemux --version
```

## 验证结果

- `validate_plugin.py C:\Users\peng8\plugins\rolemux` 通过。
- `read_marketplace_name.py` 返回 `personal`。
- `codex plugin list` 安装前显示 `rolemux@personal` 为 `not installed`。
- `codex plugin add rolemux@personal` 成功。
- `codex plugin list` 安装后显示 `rolemux@personal` 为 `installed, enabled`，版本 `0.1.0`。
- 缓存副本 `C:\Users\peng8\.codex\plugins\cache\personal\rolemux\0.1.0` 通过 `validate_plugin.py`。
- 全局 `rolemux` 命令解析到 `C:\Users\peng8\AppData\Roaming\npm\rolemux.ps1`。
- `rolemux --version` 返回 `0.1.0`。

## 边界与风险

- 插件负责让 Codex App 加载 RoleMux workflow skill；RoleMux CLI 仍需要通过 npm/GitHub/local checkout 安装到 PATH。
- 本轮没有把 RoleMux CLI 二进制或 npm 包嵌入插件，也没有让插件静默安装 CLI。
- 当前会话不会自动刷新新安装插件贡献的 skill；需要新开 Codex App 会话测试插件触发。
