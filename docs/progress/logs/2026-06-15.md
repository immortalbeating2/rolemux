# 2026-06-15 开发日志

## 本轮目标

根据用户确认的开发计划，实现 RoleMux Agents Monitor：默认支持对话内监控卡片的数据来源，同时提供 `agents --json`、`agents --tui` 和 `cancel --parent-task`。

## 实施内容

- 新增 monitor store：`src/core/agents-monitor.ts`，负责写入 `.rolemux/tasks/{parent-task-id}/monitor.json`、`events.jsonl`、`summary.md` 和 `control/cancel.json`。
- 新增 CLI 命令：
  - `rolemux dispatch --detach`
  - `rolemux agents`
  - `rolemux agents --parent-task <id>`
  - `rolemux agents --parent-task <id> --json`
  - `rolemux agents --parent-task <id> --tui`
  - `rolemux cancel --parent-task <id>`
- 新增隐藏内部入口 `_dispatch-runner`，供 `dispatch --detach` 使用参数数组启动后台执行。该入口不作为用户概念暴露。
- 同步 dispatch 路径也写入 monitor artifacts，agent 开始、完成、失败、超时、取消都会更新 snapshot 和 append-only event。
- 扩展 process runner、PTY runner 和 workflow runner，支持 `AbortSignal` 取消。
- 新增 `src/core/agents-tui.ts`，提供纯 renderer 和真实 TTY session；真实终端支持 `q`、`r`、`i`、`o`、`c`、`?`。
- 更新 Codex/Claude Skill：真实多 agent dispatch 默认使用 `dispatch --detach`，再轮询 `agents --json` 转成对话内监控卡片；TUI 由用户另开同项目终端查看。
- 更新 README 与产品 spec，记录新 CLI、monitor artifact 和 cancel 语义。

## 风险与后续建议

- 当前 TUI 是成熟的本地终端监控，不是 Web dashboard；这符合本版本边界。
- `cancel` 对普通 pipe provider 可通过 AbortSignal 终止；PTY provider 也接入取消入口，但真实 Agy/ConPTY 行为仍应在后续真实 provider 验证中继续观察。
- 当前不会重新运行失败 agent；后续可补 `resume` 或 `rerun` 类命令。
