# 2026-06-22 开发日志

## 本轮目标

修正 RoleMux 安装/卸载目标选择契约，避免默认安装把 Codex/Claude 非插件版 Skill 写入 live 目录，并把 Codex App 插件刷新与非插件 Skill 安装明确拆开。

本轮不处理 `C:\Users\peng8\.agents-skills\self-create-skills`；该目录是用户个人临时 Skill 分发/链接路径，不属于 RoleMux 产品安装流程。

## 实施内容

- 新增 `rolemux install` 目标选择：
  - 默认只安装 shared runtime：`~/.rolemux/config.toml` 与 `~/.rolemux/roles`。
  - `--codex` 才安装 Codex 非插件 Skill：`~/.codex/skills/rolemux-workflow`。
  - `--claude` 才安装 Claude 非插件 Skill：`~/.claude/skills/rolemux-workflow`。
  - `--codex-plugin` 才刷新 Codex App 插件源和缓存。
- 新增 dry-run 结构化信息：
  - `targets` 保持为本次计划目标。
  - `targetPlan` 标记 `planned`、`skipped-existing`、`optional-not-selected`。
  - `optionalTargets` 展示未选择但可用的 `--codex`、`--claude`、`--codex-plugin`。
- 调整 `rolemux uninstall`：
  - 默认清理 shared runtime 与 Codex/Claude 非插件 Skill。
  - `--codex`、`--claude`、`--codex-plugin` 只处理显式目标。
  - 默认不删除 Codex App 插件；插件必须显式 `--codex-plugin`。
- 追加通用 Skill 源：
  - 新增 `skills/rolemux-workflow/SKILL.md` 作为唯一通用内容源。
  - 删除仓库内 `skills/codex/` 与 `skills/claude/` 宿主专属 Skill 源副本。
  - 安装器从通用源复制到 Codex/Claude 非插件目标和 Codex App 插件目标。
- 更新 README、产品 spec、release checklist、状态文档和时间线。
