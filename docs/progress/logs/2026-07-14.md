### Windows TUI

- 初次 PTY 复测发现两个通用问题：Node 对 `?` 只提供 `chunk="?"`、`key.name` 为 undefined；`close()` 恢复 raw mode 后没有 pause stdin，导致 `q` 停止重绘但 CLI 进程不退出。
- 两个问题均按 TDD 修复：`?` 同时识别 chunk，close 时调用 `input.pause()`；新增真实流回归测试。
- 修复后在 Windows `node-pty` 中对真实 Grok monitor 快照依次输入 `?`、`i`、`o`、`r`、`q`，逐屏断言 Help、expanded detail、artifact footer、refreshed，最终 exit code 0。
- 第二轮输入 `c`、`c`、`q`，确认取消提示、`cancel requested` footer 和 exit code 0。
- 可见 Windows Terminal 专用窗口能够启动真实 TUI；但 computer-use 原生管道不可用，GUI SendKeys 即使聚焦并点击专用窗口也未可靠送达，因此没有把桌面视觉切换记为通过。Windows PTY 已覆盖真实 TTY、raw mode、keypress 和退出生命周期。
