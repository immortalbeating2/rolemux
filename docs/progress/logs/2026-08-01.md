## 六项 Evidence Workflow 增强

- 统一结果：显式 `--result-json` 写入版本化 `result.json`；结构解析失败保留原始 `output.md` 并标记 failed。
- 可复现信息：新 metadata 保存 Git HEAD、prompt/config SHA-256、provider executable/version、未知模型的 `not-reported`，dispatch 子任务同样覆盖。
- 预算：`run --max-attempts` 限制 primary+fallback 次数，`run --timeout-ms` 是整个 fallback 链 deadline；metadata 记录 `attemptsUsed/deadlineReached`。
- 结构化讨论：候选互相隔离，counter 只读取匿名候选，验证 manifest 只接受 `executable + args[]`，final `result.json` 的 verification 由真实执行结果覆盖。
- 路由：五个 adapter 声明 `architecture/research/implementation/ui-review/failure-review` 能力，`route` 使用固定优先级与 availability/exclude/maxProviders；显式 providers 不被覆盖。
- Eval Pack：从 v1/20 案例升级到 v2/26 案例，structured 模式增加 counter-review，总调用数从 9 变为 10；parser 仍接受 v1。
